## A. Pedoman Wawancara Beban Kognitif (studi pendahuluan)
Identitas: Kode siswa ___ · Kelas ___ · Tanggal ___ · Durasi ___
1. Ceritakan pengalamanmu belajar matematika di kelas. Bagian mana yang paling sulit?
2. Saat guru menjelaskan, apakah kamu pernah merasa "terlalu banyak informasi sekaligus"? Kapan?
3. Lebih mudah memahami materi lewat apa: teks, gambar, video, atau contoh soal? Mengapa?
4. Saat mengerjakan soal cerita, langkah mana yang paling membingungkan: memahami soal, membuat model/rumus, menghitung, atau memeriksa jawaban?
5. Apakah kamu sudah tahu tentang pola bilangan/barisan? Coba jelaskan dengan bahasamu.
6. Apa yang membuatmu cepat lelah atau bosan saat belajar matematika?
7. Apakah kamu punya HP? Biasanya dipakai untuk apa? Bagaimana kuota/internetnya?
8. Aplikasi belajar seperti apa yang kamu sukai? Apa yang tidak kamu sukai?
9. Jika ada aplikasi matematika, fitur apa yang paling membantu (petunjuk, contoh, permainan, suara)?

## C. Lembar Uji Coba Soal (Think-Aloud): **TUGAS MINGGU INI**
Petunjuk peneliti: minta siswa membaca soal **dengan suara keras** dan mengucapkan apa yang dipikirkan saat mengerjakan. Catat waktu. Jangan membantu kecuali siswa benar-benar berhenti (catat sebagai "butuh bantuan").

Kode siswa: ___ Tanggal: ___

| ID soal | Mulai–selesai (detik) | Jawaban siswa | Benar? (1/0) | Butuh bantuan? | Persepsi* (1–4) | Paas (1–9) | Kata/kalimat yang tidak dipahami | Catatan ucapan siswa |
|---|---|---|---|---|---|---|---|---|
| G01 | | | | | | | | |
| G02 | | | | | | | | |
| … | | | | | | | | |

\*Persepsi kesulitan: **1** = terlalu mudah · **2** = sesuai · **3** = sulit · **4** = terlalu sulit

Pertanyaan setelah tiap soal:
1. Apakah soal ini bisa kamu kerjakan? Bagian mana yang membuatmu ragu?
2. Apakah kalimatnya mudah dipahami? Kata mana yang membingungkan?
3. Apakah ceritanya pernah kamu temui di kehidupan sehari-hari?

**Keputusan revisi**: Persepsi 1 + benar cepat → tambah tantangan/naikkan level. Persepsi 2 → pertahankan. Persepsi 3 → tambah hint/worked example. Persepsi 4 atau Paas ≥ 8 → sederhanakan kalimat/angka atau pecah menjadi sub-soal.

## E. Angket Beban Kognitif (adaptasi Leppink dkk., 2013)
Skala 0 (sama sekali tidak) – 10 (sangat setuju).
**Intrinsik (IL)**
1. Materi pada pelajaran ini sangat rumit.
2. Soal-soal pada pelajaran ini sangat rumit.
3. Rumus dan konsep pada pelajaran ini sangat rumit.

**Ekstrinsik (EL)**
4. Penjelasan dalam aplikasi ini sangat tidak jelas.
5. Penjelasan dalam aplikasi ini kurang efektif untuk belajar.
6. Penjelasan dalam aplikasi ini penuh dengan kata-kata yang tidak jelas.

**Germane (GL)**
7. Pelajaran ini benar-benar menambah pemahamanku tentang barisan dan deret geometri.
8. Pelajaran ini benar-benar menambah pemahamanku tentang rumus-rumus yang dibahas.
9. Pelajaran ini benar-benar menambah pengetahuanku tentang penggunaan matematika dalam kehidupan sehari-hari.
10. Pelajaran ini benar-benar menambah pemahamanku tentang konsep yang dibahas.

Skor = rata-rata per dimensi. Yang diharapkan: EL rendah, GL tinggi.

## F. System Usability Scale (SUS; Brooke, 1996), versi Indonesia
Skala 1 (sangat tidak setuju) – 5 (sangat setuju).
1. Saya ingin sering memakai aplikasi ini.
2. Aplikasi ini terlalu rumit.
3. Aplikasi ini mudah digunakan.
4. Saya butuh bantuan orang lain untuk memakai aplikasi ini.
5. Fitur-fitur aplikasi ini menyatu dengan baik.
6. Banyak hal yang tidak konsisten di aplikasi ini.
7. Kebanyakan teman saya akan cepat bisa memakai aplikasi ini.
8. Aplikasi ini membingungkan.
9. Saya percaya diri saat memakai aplikasi ini.
10. Saya harus belajar banyak hal dulu sebelum bisa memakai aplikasi ini.

Skor: item ganjil (skor − 1), item genap (5 − skor), jumlahkan, lalu × 2,5 → 0–100. ≥ 68 = dapat diterima.
